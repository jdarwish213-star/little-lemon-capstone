# Little Lemon Restaurant - Front-End Capstone Project

This project is the final capstone project for the **Meta Front-End Developer** professional certificate on Coursera. It is a responsive web application for the Little Lemon restaurant, featuring a fully functional table reservation system built with React.

## Features
- **Interactive Reservation Form**: Users can select a date, time, number of guests, and occasion.
- **Form Validation**: Client-side validation ensuring correct inputs before submission.
- **State Management**: Uses React `useReducer` and custom API functions to manage available booking times dynamically.
- **Responsive Design**: Fully adaptable to mobile, tablet, and desktop viewports.
- **Unit Tests**: Includes test suites for form components and state functions.
